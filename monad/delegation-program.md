# Monad Validator Delegation Program

> Reviewed 2026-09-15 against the [official Monad Validator Delegation Program](https://docs.monad.xyz/node-ops/validator-delegation-program). This is an eligibility reference, not an application, allocation, staking, or validator-operation workflow.

## Published scope and current boundary

The official page describes a Validator Delegation Program (VDP) for Monad validators and links its published criteria. It also says the application form is forthcoming. This Hub therefore does **not** present an application link, an open-intake claim, a guaranteed allocation, or a Foundation eligibility decision.

The page header is dated April 22 while the body includes an April 24 stage-two adjustment. Treat its terms as a dated policy snapshot and recheck the official page before any application or delegation decision.

## Published eligibility evidence

The reviewed official policy describes these requirements:

- continuous Monad testnet operation;
- 98% uptime;
- four weeks of testnet intake evidence;
- KYC/KYB and metrics access; and
- a delegation-cap policy described as permanently 10%, temporarily 15% after the observed April 24 adjustment (superseding a previous 20% figure).

These are policy criteria, not proof that any individual validator satisfies them. The temporary 15% value is not a permanent rule. Testnet participation is evidence for the mainnet-facing program; it is not a separate testnet allocation promise.

## Reusable program-review record

Any network can use this Node Ops module only when it publishes a dated authoritative policy. Record the authority URL, review date, target network, eligibility window, stated caps, evidence owner, application status, and the conditions that remain unpublished. Keep policy facts separate from locally observed performance and never infer an approval from a public uptime chart.

Before an operator acts, verify the current policy, application availability, validator identity, evidence window, and privacy/legal handling through the authoritative channel. Wallet connection, transaction signing, stake movement, KYC/KYB submission, metrics sharing, or third-party contact remain explicit operator decisions outside this Hub.
