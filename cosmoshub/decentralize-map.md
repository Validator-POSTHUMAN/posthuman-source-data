# Cosmos Hub Mainnet Decentralization Map

Interactive map for public Cosmos Hub mainnet RPC and consensus peer
infrastructure tracked by POSTHUMAN.

The map shows:

- POSTHUMAN and chain-registry public RPC endpoint health and DNS location;
- public seeds and persistent peers from the Cosmos chain-registry;
- globally routable peers observed through public Cosmos Hub RPC `/net_info`;
- country, provider/ASN and status distribution.

Data feed: `cosmoshub/decentralize-map.json`.

> Private validator IPs, signer locations, sentry topology and non-global
> addresses are not published. Public peer observations do not prove validator
> signer locations.
