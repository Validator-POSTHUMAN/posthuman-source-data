# JunoClaw validator skill

The [JunoClaw G2 validator operations skill](https://github.com/Validator-POSTHUMAN/AI-skills-for-networks/tree/main/junoclaw) helps an agent check threshold-share onboarding, coordinated starts, certified state sync, finalized-height progression and signing evidence.

It is operator-neutral: private host inventory, coordinator messages and key custody remain with the operator. The skill never grants authority to copy a private share, run two signers, reset signer journals or change the validator set. Read the [raw SKILL.md](https://raw.githubusercontent.com/Validator-POSTHUMAN/AI-skills-for-networks/main/junoclaw/SKILL.md) and the [installation guide](/node-ops/junoclaw-testnet/installation).
